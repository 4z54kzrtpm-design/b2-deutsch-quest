# B2 Deutsch Quest – Mobile PWA

- B2 어휘: 기존 카드 데이터 유지
- B2 Redemittel/Satzbausteine: 기존 데이터 유지
- 시험형 문제: 기존 문제 데이터 유지
- 문장 만들기: 표현을 사용해 직접 독일어 문장 작성 + 모범문장 비교
- Sprechen: B2 주제별 20~60초 말하기 + 브라우저 음성인식(de-DE) + 추천 표현/분량 자기점검
- 학습 기록: localStorage 저장
- 휴대폰 최적화

## Sprechen 사용
마이크 버튼을 누르면 브라우저의 Speech Recognition API가 독일어 음성을 텍스트로 변환합니다. 브라우저 지원 여부에 따라 기능이 달라질 수 있으며, 지원되지 않는 경우 Chrome/Edge 등 다른 브라우저를 사용할 수 있습니다.

현재 자동 평가는 발화 내용의 텍스트를 바탕으로 **추천 표현 사용 여부와 말한 분량**을 점검합니다. 문법·발음 정확도를 전문적으로 판정하는 AI 평가 기능은 포함하지 않습니다.

웹에 올린 뒤 HTTPS 주소에서 사용하세요. PWA 설치에는 HTTPS 주소가 필요합니다.
